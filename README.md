## 🖌 스케치에 색을 채워 그림 그리는 드로잉앱

**Fill Sketch** 스케치 위에 색을 칠하여 그림을 그리고, 저장하는 간단한 드로잉 앱입니다.

Jetpack Compose를 사용하여 간단하고 직관적인 UI를 설계하였습니다.

Multi-module 아키텍처 설계를 통해 여러 앱에 적용되어 있으며, 공통 부분의 module을 포함한 저장소입니다.
